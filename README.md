# Ателье «Жар птица»

Сайт ателье в Прокопьевске: реставрация подушек, одеял и перин, пошив постельного белья. Текущая версия проекта — **1.4.5**.

## Возможности

- Страницы услуг, прайс-листа, контактов и политики обработки персональных данных.
- Форма обратного звонка с проверкой полей и отправкой заявки через сервер в MAX.
- Светлая и тёмная темы с сохранением выбора посетителя.
- Адаптивная вёрстка, сравнение фотографий до и после, Яндекс Метрика и метаданные для поисковых систем.

## Технологии

- Клиент: React, TypeScript, Vite и SCSS.
- Сервер формы: Node.js и встроенный HTTP-сервер (`server/server.js`).
- Развёртывание: GitHub Actions и VPS.

## Локальный запуск

Текущая версия проекта проверялась с Node.js 24.

```bash
git clone https://github.com/jariknik94-ai/zhar-ptica.git
cd zhar-ptica
npm ci
npm run dev
```

Для работы формы создайте `server/.env` с переменными `MAX_BOT_TOKEN` и `MAX_CHAT_ID`, затем запустите сервер в отдельном терминале:

```bash
node server/server.js
```

Сервер разработки Vite перенаправляет запросы `/api` на `localhost:3001`. Без запущенного сервера и корректных настроек отправка заявок недоступна. Не добавляйте `.env` в репозиторий.

## Проверка и сборка

```bash
npm run lint
npm run build
npm run preview
```

Сборка записывается в `dist`. После отправки изменений в ветку `main` GitHub Actions запускает развёртывание на VPS.

## Лицензия
