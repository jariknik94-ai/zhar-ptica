# 🕊️ Ателье «Жар птица»

Сайт ателье в Прокопьевске, которое занимается реставрацией пухо-перьевых изделий и пошивом постельного белья. Посетители могут узнать об услугах, посмотреть цены и оставить заявку на обратный звонок.

🌐 **Сайт:** [ательежарптица.рф](https://xn--80aaasagpu3bjqh7c5d.xn--p1ai/) · 📦 **Версии:** [релизы проекта](https://github.com/jariknik94-ai/zhar-ptica/releases)

---

### ✨ Возможности

* **Главная страница:** услуги, преимущества, этапы работы, фотографии «до и после», отзывы и контакты.
* **Прайс-лист:** цены на реставрацию и пошив.
* **Обратный звонок:** форма с проверкой полей и отправкой заявки в MAX через сервер.
* **Оформление:** адаптация под разные экраны, светлая и тёмная темы с сохранением выбора.
* **Поиск и аналитика:** метаданные страниц, карта сайта, микроразметка и Яндекс Метрика.

### 🛠️ Технологии

* **Клиент:** React, TypeScript, Vite, React Router и SCSS.
* **Сервер заявок:** Node.js, встроенные модули HTTP и HTTPS, MAX Bot API.
* **Развёртывание:** GitHub Actions и VPS.

### 🚀 Локальный запуск

Для работы потребуются Node.js и npm. Проект проверялся с **Node.js 24**.

1. Клонируйте репозиторий и установите зависимости:

   ```bash
   git clone https://github.com/jariknik94-ai/zhar-ptica.git
   cd zhar-ptica
   npm ci
   ```

2. Запустите сайт:

   ```bash
   npm run dev
   ```

   Откройте адрес, который выведет Vite в терминале. Сайт можно просматривать без запуска сервера заявок.

3. Чтобы работала отправка формы, создайте файл `server/.env`:

   ```dotenv
   MAX_BOT_TOKEN=токен_бота
   MAX_CHAT_ID=идентификатор_чата
   ```

   Запустите сервер в отдельном терминале:

   ```bash
   node server/server.js
   ```

   Сервер использует порт `3001` по умолчанию. Vite перенаправляет запросы `/api` на `http://localhost:3001`. При изменении `PORT` на сервере нужно также обновить адрес прокси в `vite.config.ts`. Для реальной отправки нужны действующие настройки MAX; файл `server/.env` не добавляется в Git.

### ✅ Проверка и сборка

```bash
npm run lint      # проверка ESLint
npm run build     # проверка TypeScript и сборка в dist/
npm run preview   # локальный просмотр собранного сайта
```

`npm run preview` предназначен для просмотра сборки; прокси для заявок настроен только для сервера разработки. Для полноценной проверки формы требуется отдельно настроить маршрутизацию `/api/booking` к серверу заявок.

### 📁 Структура проекта

```text
src/
├── components/       # блоки, навигация и форма заявки
├── pages/            # главная, прайс-лист, политика и страница 404
├── data/             # цены и текст политики
├── assets/           # изображения и значки
└── styles/           # глобальные стили
public/               # шрифты, иконки, robots.txt и sitemap.xml
server/server.js      # обработчик заявок и отправка в MAX
```

Цены редактируются в `src/data/prices.ts`, текст политики — в `src/data/politics.ts`. Метаданные страниц находятся в компоненте `src/components/SEO/SEO.tsx` и самих страницах.

### 📦 Развёртывание

Отправка изменений в ветку `main` запускает workflow `.github/workflows/deploy-vps.yml`: он обновляет файлы на VPS, устанавливает зависимости, собирает сайт и отправляет URL в IndexNow. Для работы workflow требуются настроенные секреты GitHub Actions и доступ к серверу. Сервер заявок запускается отдельно.
